## Repository Overview

This directory contains a collection of anime/manga character stickers and emojis (表情包), not a software development project. The content is organized by character names from various series including:

- **BanG Dream! Girls Band Party**: nina, nijika, tomori, momoka, subaru, hitori, ikuyo, soyo, taki, tomo, rupa, sakiko, ryo, uika, nyamu, mutsumi, raana, umiri, gbc
- **Solo Leveling**: KB
- **BanG Dream! It's MyGO!!!!!**: anon
- **Other**: mana

## Directory Structure

Each subdirectory is named after a character and contains:
- `.png` - Static sticker images
- `.gif` - Animated sticker images
- `.webp` - WebP format images

Filenames use Chinese and English descriptions of expressions and emotions.
